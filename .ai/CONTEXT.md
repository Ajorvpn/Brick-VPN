## Workflow

**Before editing**: check `.internal/PROGRESS.md` for active blockers and completed work.

**During work**: respect the file location conventions:
- Kotlin native module: `packages/expo-v2ray/android/src/main/java/expo/modules/v2ray/`
- Config parser: `packages/core-api/src/config-parser.ts`
- State stores: `packages/core-api/src/stores/`
- React hooks: `apps/mobile/src/hooks/`
- Native VPN gitignored: `apps/mobile/android/`, `packages/expo-v2ray/android/libs/libbox.aar`

**After completing a task**:
1. Update `.internal/PROGRESS.md`:
   - Mark checklist items complete
   - Add session log entry
   - Update active blockers
2. If architectural: append to `.internal/DECISIONS.md`
3. If milestone-level: update table in `docs/ROADMAP.md`

## Rules

- Don't touch AndroidManifest.xml, MainApplication.kt, MainActivity.kt without explicit request (auto-generated by prebuild)
- Don't add telemetry, analytics, crash reporting (see D005)
- Don't add root detection (see D004)
- Don't hardcode server IPs, credentials, subscription URLs
- Don't use deprecated `EncryptedSharedPreferences` — use `expo-secure-store` + MMKV
- Preserve 2-space indentation throughout
